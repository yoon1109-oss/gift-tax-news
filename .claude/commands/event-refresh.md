# 계좌 이벤트 갱신

`api/events.js`의 증권사 자녀계좌 이벤트를 재조사해 갱신하고 배포한다.

## 절차

1. `date +%F` 로 오늘 확인, `git pull --rebase`

2. **EVENTS 각 이벤트 검수** — 종료일이 지났거나 임박한 것 우선
   - 공식 페이지 확인. JS 렌더(SK 등)는 브라우저로 판독, 이미지 배너는 Read(비전)
   - 진행중이면 기간·혜택 갱신 / 종료+후속없음이면 **PENDING(확인필요)로 이동**(삭제 금지)

3. **PENDING 각 증권사 재조사** — `WebSearch("[증권사] 미성년 자녀 계좌 개설 이벤트 [연도]")`
   - 확정 진행중이면 EVENTS로 승격. **출처 2개 이상 교차 확인 필수**, 아니면 PENDING 유지
   - 키움은 robots 차단이라 크롤링하지 말고 검색으로만 판단

4. **날짜·메모 갱신**
   - `CHECKED_AT` → 항상 오늘
   - 실데이터가 바뀐 경우에만 `UPDATED_AT` → 오늘
   - 바뀐 항목마다 `CHANGES` 맨 앞에 `{date, text}` 추가. text는 비개발자도 아는 쉬운 한 문장
     (예: "SK증권 이벤트가 8월분으로 갱신되었어요")

5. **검증·배포**
   - `node --check api/events.js`
   - 커밋 → `git push origin main`
   - 배포 후 `curl -s https://gift-tax-news.vercel.app/api/events` 로 실제 반영 확인

6. **보고**: 추가·이동·갱신된 이벤트, CHANGES 문구, 확인 출처, 커밋 해시

## 주의

- 어떤 증권사도 목록에서 완전 삭제하지 않는다 (EVENTS ↔ PENDING 이동만)
- 기간 경과만으로 만료 처리하지 말고 반드시 후속 이벤트를 먼저 확인한다
- 혜택이 이미지에만 있는 경우, 텍스트로 안 읽히면 기존 값을 함부로 덮지 않는다
