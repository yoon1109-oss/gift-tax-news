증여 기사

뉴스 검색

데이터 출처 · 네이버 뉴스 검색 오픈 API

  • 수집 — 키워드 자녀 증여로 검색해 관련도 높은 순으로 최대 300건을 가져옵니다.
  • 오너 승계성 기사 제외 — “○○그룹 회장이 자녀에게 지분 증여”처럼 기업 오너의 증여 뉴스는 제외합니다.‘세무사회장’ 등 정보성 기사는 유지합니다.
  • 중복 통합 — 여러 언론사가 전한 같은 소식은 대표 기사 1건으로 통합합니다.회사명이 같거나 내용이 거의 같으면 동일 기사로 판단합니다.
  • 정렬 — 연관도 상위 3건을 먼저 노출하고, 나머지는 최신순으로 정렬합니다.

연관도 상위 3건 선정 방식

  1. 네이버가 관련도순으로 제공한 순서를 기준값으로 보관합니다.
  2. 각 기사에 ‘증여 정보 점수’를 부여합니다. 아래 단어가 제목에 있으면 2점, 본문에 있으면 1점을 더합니다.
  3. 점수가 높은 순으로 정렬합니다. 점수가 같으면 1단계의 네이버 관련도순을 따릅니다.
  4. 상위에서 3건을 선정하되 같은 회사·같은 사건은 1건만 포함해, 서로 다른 대표 기사 3건이 되도록 합니다.

파이 기사

뉴스 검색

데이터 출처 · 네이버 뉴스 검색 오픈 API

  • 수집 — 키워드 한화생명 파이 증여로 검색합니다.
  • 한정 — 한화생명이 언급된 기사만 남깁니다.
  • 공통 처리 — 오너 승계성 기사 제외, 중복 통합은 증여 기사와 동일합니다.

블로그 검색

블로그 검색

데이터 출처 · 네이버 블로그 검색 오픈 API + 네이버 블로그 공감 집계(비공식)

  • 수집 — 키워드 한화생명 파이로 블로그 글(제목·요약·블로그명·작성일)을 가져옵니다.
  • 공감수(좋아요) — 검색 API가 공감수를 제공하지 않아, 글마다 네이버 공감 집계를 별도로 조회해 표시합니다.공식 문서가 없는 경로라 네이버 변경 시 표시되지 않을 수 있으며, 네이버 블로그 글에만 적용됩니다.

계좌 이벤트

큐레이션

데이터 출처 · 외부 API 없음 — 수기 정리 데이터 + 주간 자동 확인

  • 구성 — 진행 중인 5개 증권사(미래에셋·삼성·토스·한국투자·우리투자)의 혜택·기간·공식 링크와, 조회하는 19개 증권사 명단을 제공합니다.
  • 주간 자동 확인 — 매주 월요일 오전 10시에 각 증권사 공식 페이지를 열람하고(혜택이 이미지 배너면 판독), 뉴스도 함께 검색해 진행 이벤트의 변동 여부를 확인합니다.토스(앱 전용)·키움(자동접근 차단) 등 일부는 자동으로 읽을 수 없어, 자동 확인으로 변동을 감지하고 최종 반영은 담당자가 확인해 갱신합니다.
  • 날짜 관리 — 정리 기준(데이터가 바뀐 날)과 마지막 확인(자동 재조사가 실행된 날)을 구분해 표시합니다.
