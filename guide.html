뉴스 검색

키워드 4종

데이터 출처 · 네이버 뉴스 검색 오픈 API

  • 키워드 전환 — 상단 칩으로 네 가지 검색어를 오갑니다.자녀 증여 · 가족 자산 관리 · 금융 플랫폼 · 한화생명 파이 증여
  • 수집 — 관련도 높은 순으로 최대 300건을 가져옵니다.
  • 노이즈 기사 제외 — 증여 ‘정보’와 거리가 먼 아래 유형은 목록에서 제외합니다.① 기업 오너 승계: 회장·부회장·오너·총수·창업주·일가·지분·2~4세·가업승계·기업승계 등 · ② 부동산/편법/정치성: 부동산·아파트·주택·빌딩·상가·토지·오피스텔·근저당·편법증여·셀러 파이낸싱·집주인 대출·대통령·이재명 등. (단 ‘세무사회장’ 등 정보성 기사는 예외로 유지)
  • 중복 통합 — 여러 언론사가 전한 같은 소식은 대표 기사 1건으로 통합합니다.회사명이 같거나 내용이 거의 같으면 동일 기사로 판단합니다.
  • 정렬 — 연관도 상위 4건을 먼저 노출하고, 나머지는 최신순으로 정렬합니다.‘한화생명 파이’는 결과가 적어 연관도 구분 없이 최신순으로만 보여줍니다.

연관도 상위 4건 선정 방식

  1. 네이버가 관련도순으로 제공한 순서를 기준값으로 보관합니다.
  2. 각 기사에 연관도 점수를 부여합니다. 아래 표의 단어가 제목·본문에 있으면 배점만큼 더합니다.
  3. 점수가 높은 순으로 정렬합니다. 점수가 같으면 1단계의 네이버 관련도순을 따릅니다.
  4. 상위에서 4건을 선정하되 같은 회사·같은 사건은 1건만 포함해, 서로 다른 대표 기사 4건이 되도록 합니다.
  5. 300건을 모두 받은 뒤 전체 기준으로 다시 선정합니다. 뒤늦게 들어온 상위 기사가 누락되지 않도록 하기 위함입니다.

블로그 검색

블로그 검색

데이터 출처 · 네이버 블로그 검색 오픈 API + 네이버 블로그 공감 집계(비공식)

  • 수집 — 키워드 한화생명 파이로 블로그 글(제목·요약·블로그명·작성일)을 가져옵니다.
  • 공감수(좋아요) — 검색 API가 공감수를 제공하지 않아, 글마다 네이버 공감 집계를 별도로 조회해 표시합니다.공식 문서가 없는 경로라 네이버 변경 시 표시되지 않을 수 있으며, 네이버 블로그 글에만 적용됩니다.

이벤트

서브탭 · 계좌 이벤트
  • 주간 자동 확인 — 매주 월요일 오전 10시에 각 증권사 공식 페이지를 열람하고(혜택이 이미지 배너면 판독), 뉴스도 함께 검색해 진행 이벤트의 변동 여부를 확인합니다.토스(앱 전용)·키움(자동접근 차단) 등 일부는 자동으로 읽을 수 없어, 자동 확인으로 변동을 감지하고 최종 반영은 담당자가 확인해 갱신합니다.

이벤트

서브탭 · 친구 초대 이벤트
  • 대상 — 증권사가 진행하는 친구 초대·추천 이벤트를 모읍니다.증권사는 자본시장법상 재산상 이익 제공 제한이 있어 이 유형 자체가 드뭅니다.
  • 확인 기준 — 공식 페이지와 뉴스 등 출처 2곳 이상에서 확인된 것만 올립니다.블로그가 홍보하는 추천인 코드는 증권사 공식 이벤트가 아닐 수 있어 반영하지 않습니다.
  • 갱신 — 계좌 이벤트와 함께 매주 월요일 오전 10시에 재확인합니다.

앱 리뷰

파이 앱

데이터 출처 · 구글 플레이 · 애플 앱스토어

  • 스토어 평점 — 두 스토어의 평점과 별점 개수를 함께 보여줍니다.
  • 리뷰 목록 — 글로 작성된 리뷰를 스토어 구분 없이 최신순으로 모아 보여줍니다. 별점·작성일·작성자·앱 버전, 개발사 답변이 있으면 함께 표시합니다.
  • 별점 수와 리뷰 수가 다른 이유 — 별점만 남기고 글을 쓰지 않은 이용자는 목록에 나오지 않습니다. 그래서 평점 개수보다 글 리뷰가 적습니다.애플은 공식 리뷰 피드가 자주 비어 있어, 앱스토어 페이지에 실제 표시되는 리뷰를 함께 읽어 옵니다.

세무사회 보도자료

외부 공지

데이터 출처 · 한국세무사회 보도자료 게시판

  • 수집 — 보도자료 목록 1페이지를 가져와 제목·날짜를 표시하고, 상세는 세무사회 홈페이지로 연결합니다.제목 앞의 ‘[보도자료]’ 표기는 떼고 전체 제목이 잘리지 않게 보여줍니다.
  • 연관도 분류 — 아래 키워드가 들어간 보도자료는 연관도 높음으로 상단에 따로 모읍니다.증여, 상속, 증여세, 상속세, 유산, 가업승계, 물려, 세대생략, 세무대리, 세무사법, 오인광고, 세무플랫폼, 자격

통계

지표

데이터 출처 · 국세통계 6.3.1 증여세 신고 현황Ⅰ(납세지) — 2025년 신고분 (TASIS)

  • 읽기 전 확인 — 수치를 잘못 읽지 않도록 세 가지 전제를 상단에 안내합니다.① 이 통계는 과세미달을 제외하고 작성됩니다 — 공제한도 이내라 낼 세금이 없는 증여(예: 미성년 자녀 10년 2천만원 이내)는 집계되지 않습니다 · ② 증여재산공제는 실제 증여액이 아니라 세금에서 빼주는 공제 금액의 합계입니다 · ③ 직계존비속 공제에는 창업자금·가업승계 주식 공제(5억원)가 포함돼 있습니다.
  • 주요 지표 — 자녀 증여(직계존비속), 친족 증여, 혼인·출산 공제, 10년 합산(사전증여) 네 가지를 상단에 정리합니다.
  • 요약 지표 — 증여 시장 규모, 증여재산공제 세부(직계존비속·배우자·혼인·출산·그 밖의 친족·장애인), 과세 흐름(과세가액→과세표준→산출세액→자진납부세액)을 표시합니다.
  • 로우 데이터 — 최하단에 2025년 전국 합계 원본 표를 그대로 제공합니다.
  • 2025년 단일 기준 — 모든 수치를 ‘2025년 신고 현황’ 하나로 맞췄습니다.관계별·연령별 통계는 국세청이 2024년까지만 공표해 연도가 어긋나므로 쓰지 않습니다.
